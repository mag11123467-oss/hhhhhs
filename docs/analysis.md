# Анализ предметной области: AccessEvent

## 1. Описание предметной области

AccessEvent — платформа для организации мероприятий с акцентом
на доступность для людей с нарушениями слуха.

## 2. Сущности и атрибуты

| Сущность | Атрибуты | Описание |
|----------|----------|----------|
| Event | id, title, date, location, description | Мероприятие |
| Participant | id, name, email, phone | Участник |
| Organizer | id, name, contact, rating | Организатор |
| Registration | id, event_id, participant_id, status | Регистрация |
| Notification | id, event_id, type, message, color | Уведомление |
| Review | id, event_id, participant_id, rating, text | Отзыв |
| Category | id, name, description | Категория |
| Message | id, event_id, user_id, text | Сообщение чата |
| Role | id, name, description | Роль пользователя |

## 3. Бизнес-процессы

### 3.1. Создание мероприятия
Организатор создаёт мероприятие.

### 3.2. Регистрация
Участник регистрируется на мероприятие.

### 3.3. Уведомление
Система показывает цветной баннер за 30 минут.

### 3.4. Чат
Участник пишет в текстовый чат.

### 3.5. Отзывы
Участник оставляет отзыв после мероприятия.

## 4. Роли пользователей

- **Организатор** — создаёт мероприятия
- **Участник** — посещает мероприятия
- **Администратор** — контролирует платформу
- **Гость** — просматривает без регистрации
