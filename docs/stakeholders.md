# Стейкхолдеры проекта AccessEvent

Стейкхолдеры — все заинтересованные лица, которых затрагивает система.
Для AccessEvent выделены четыре основные группы.

## Таблица стейкхолдеров

| Стейкхолдер | Что ему нужно от системы |
|-------------|--------------------------|
| Организатор | Создавать и управлять мероприятиями, видеть статистику регистраций |
| Участник с нарушениями слуха | Визуальные уведомления, текстовый чат, цветовая индикация статусов |
| Администратор | Контроль, модерация, статистика, блокировка нарушителей |
| Переводчик жестового языка | Информация о мероприятиях для сопровождения участников |

## Подробное описание

### 1. Организатор
Создаёт мероприятия, управляет ими, редактирует, отменяет,
видит список зарегистрированных участников и статистику.

### 2. Участник с нарушениями слуха
Основная целевая аудитория платформы. Нуждается в:
- визуальных уведомлениях о начале мероприятия;
- цветовой индикации статусов;
- текстовом чате вместо голосового общения;
- доступном интерфейсе (WCAG 2.1 AA).

### 3. Администратор
Следит за порядком на платформе, модерирует мероприятия,
блокирует нарушителей, просматривает статистику.

### 4. Переводчик жестового языка
Получает информацию о мероприятиях для сопровождения
участников с нарушениями слуха.

## Выводы

Все стейкхолдеры заинтересованы в доступности системы.
Приоритет — участники с нарушениями слуха, так как система
ориентирована именно на них.
