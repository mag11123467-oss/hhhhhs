# AccessEvent

Веб-платформа для организации мероприятий с акцентом на доступность
для людей с нарушениями слуха.

## О проекте

AccessEvent позволяет организаторам создавать мероприятия,
а участникам — регистрироваться, получать визуальные уведомления
и общаться через текстовый чат. Система разработана в рамках
учебной практики по специальности 09.02.07 «Информационные системы
и программирование».

## Стек технологий

- Backend: Python 3.10+, Flask 2.3+
- База данных: PostgreSQL 14+
- Шаблоны: Jinja2
- CI/CD: GitHub Actions + GHCR
- Тесты: pytest

## Структура проекта

- `docs/` — предпроектная документация
- `.github/workflows/` — CI/CD проверки
- `src/` — исходный код
- `tests/` — тесты
